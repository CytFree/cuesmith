### 1.3 磁盘预算

| 场景 | 需要 |
|---|---|
| 只用内封字幕 + 字幕矩阵 + 打标（不 ASR/配音） | 十几 MB（主包 + ffmpeg） |
| + ASR（英文 small） | + ≈ 0.5 GB 模型（worker 环境另算） |
| + ASR（中文 medium） | + ≈ 1.5 GB 模型 |
| + 配音（edge-tts） | + 0.3 GB 环境 |
| + 多人声 | + 0.14 GB 环境 + 0.09 GB 模型 |
| + 本地 TTS 兜底/离线（OPT-11） | + 0.56 GB 模型（复用 diarization 的 sherpa venv，不新增环境） |
| + 保留 BGM | + 1.2 GB 环境 + 0.08 GB 权重 |
| + GUI | + 0.3 GB 环境 |
| **本机现有全部** | venv ≈ **5.4 GB** + 模型 ≈ **2.1 GB** ≈ **7.5 GB**（不含运行产物） |

> `spike/pyvideotrans/.venv` 是沿用 pyVideoTrans 的完整环境（3.57 GB）。
> 干净机器建议只建 `spike/asr/.venv` 装 faster-whisper 三项（见 README §3.3），
> 然后用 `--asr-python` / `CUESMITH_ASR_PYTHON` 指过去，可省约 2.5 GB。

## 2. 它们各自怎么被调用

```
python -m cuesmith            ← 主包（标准库 + ffmpeg）
├─ ffmpeg（PATH）              ← 抽轨 / 混音 / 烧字幕 / 打标 / 核验
├─ spike/pyvideotrans/.venv    ← asr_worker.py（faster-whisper + ctranslate2）
├─ spike/.venv311              ← python -m edge_tts（逐条合成）
├─ spike/diarization/.venv     ← diarize_worker.py（pyannote 分割 + 声纹）
│                                 tts_worker.py（本地 TTS：Kokoro / MeloTTS，OPT-11）
├─ spike/local-tts/            ← 本地 TTS 模型（可选，缺了自动跳过兜底）
├─ spike/demucs/.venv          ← python -m demucs.separate（人声/伴奏）
└─ spike/gui/.venv             ← gradio（GUI 进程自身）
```

- 全部通过**子进程 + 文件**交互，不 import 到主包；
- 解释器都支持显式指定或环境变量覆盖（见 §7），找不到时会给出明确报错而不是静默降级；
- 主包可单独分发给"只要字幕矩阵/打标"的用户。

## 4. 版本 pin：为什么不能随便升级

这些不是"保守"，是**实测崩溃过**的结论（详见需求文档 §7 与 M 文档）：

| 组件 | 不要用的版本 | 现象 | 本项目固定 |
|---|---|---|---|
| ctranslate2 | 4.8.0 / 4.8.3 | ASR 访问违例直接崩（本机 int8/float32、1/4 线程、多种指令集全复现） | **4.5.0** |
| onnxruntime | 1.31.0 / 1.23.2 | 1.31 崩溃、1.23 DLL 初始化失败 | **1.20.1** |
| torch | 2.7.1+cpu | demucs venv 里 `c10.dll` 加载失败（WinError 1114） | **2.2.2+cpu** |
| numpy | 2.x | torch 2.2 按 1.x ABI 编译 → `Numpy is not available` | **1.26.4** |
| sherpa-onnx | 1.x 旧版 | 2.0 把推理核拆到 `sherpa-onnx-core`，不再需要单独装 onnxruntime | **2.0.0** |
| gradio | 5.x/更早 | 6.x 的 Dataframe/File 参数有差异（本项目按 6.30 实测） | **6.30.0** |
| edge-tts | 未知旧版 | voice 列表/参数差异；音色下线也无提示 | **7.3.1** |

另外：**Edge-TTS 的部分音色会被微软随时下线**（本项目已踩到 `en-US-DavisNeural` 返回
`NoAudioReceived`，4 人英文配音时第 4 人会失败）。默认池已换成在线音色；自定义音色时
先点 GUI「试听」或跑一条短素材验证。

## 6. 付费项

### 6.1 一眼结论

| 渠道 | 什么时候产生费用 | 计费（内置价表示例） | 实测 | 怎么关掉 |
|---|---|---|---|---|
| **本地 ASR / 说话人分离 / BGM 分离** | 始终 | 0 | 只耗 CPU | 不用关 |
| **Edge-TTS** | 配音时 | **0**（微软免费在线 TTS，无 Key） | 154s 素材配音 ¥0 | 不用关（换云端复刻才会付费） |
| **微软免费翻译** | 翻译时（默认） | **0** | demo2 免费 MT 10s 完成 | 不用关 |
| **DeepSeek LLM 翻译** | 加 `--llm` 或 GUI 勾「LLM 翻译」 | CNY **2 / 3** 每百万 token（输入/输出） | 央视 154s ≈ **¥0.0134–0.0165**；4 人 56.9s ≈ **¥0.0065** | 不加 `--llm`（默认走免费 MT） |
| **阿里云百炼 CosyVoice（声音复刻/云端 TTS）** | 传 `--tts-command tools/tts_dashscope.py` | USD **0.14335 / 万字符** | 274 字符 ≈ **$0.0039**（约 ¥0.028） | 不传 `--tts-command`（默认 edge-tts） |
| 火山引擎 / MiniMax / Fish / ElevenLabs | 未接或仅脚本 | — | — | 未接，不产生费用 |
| OpenAI 官方 / 其他 OpenAI 兼容 | 指过去才会用 | 按对方价格 | — | 用 `CUESMITH_LLM_BASE_URL` 指向非付费服务 |

### 6.2 成本是怎么算的

- **口径 = 产物累计**：只读产物报告（`translate.json` 的 token、`dub_report.json` 的字符），
  离线、不调服务商账单；缓存重跑数字不变；`--force`/`--regenerate-tts` 重跑不累计历史；
- 分项保留原币种，展示金额按 `fx` 折算（默认 `USD→CNY 7.2`，`display_currency=CNY`）；
- 价表是**示例值**，DeepSeek 调价/DashScope 账单请用 `--pricing` 深合并覆盖：

```json
{
  "llm": {"deepseek": {"input_per_million": 2.0, "output_per_million": 3.0, "currency": "CNY"}},
  "tts": {"dashscope": {"per_10k_chars": 0.14335, "currency": "USD"}},
  "fx": {"USD": 7.2}
}
```

```powershell
python -m cuesmith cost --work work\run --pricing 我的价表.json
python -m cuesmith cost --work work\run --json
```

- 金额是**估算，不是账单**；未知渠道按 0 元并提示。

### 6.3 想 100% 免费跑

```powershell
# 不勾 LLM、不传 tts-command：本地 ASR + Edge-TTS + 微软免费 MT
python -m cuesmith pipeline --src a.mp4 --out work\free --src-lang en --tgt-lang zh
```

免费路径的限制：微软免费翻译无 SLA、可能限流/SSL 抖动；Edge-TTS 依赖微软在线服务，
音色可能被下线。要稳定/更好的翻译质感再开 DeepSeek。

## 9. 迁移/重装注意

- **venv 不要直接拷贝**（路径写死），按 §1/README 重装；模型目录可以直接拷；
- 只拷模型时确认 `model.bin` 在目录下（CTranslate2 要求平铺），HF snapshot 结构也支持；
- 离线环境：模型下载齐后可离线跑本地 ASR/分离/BGM/GUI；Edge-TTS、免费 MT、DeepSeek
  都需要网络；`--provider command` + 本地 MT 命令可完全离线翻译；
- 换机器后先跑 `python tools\run_samples.py --out work\regression` 确认环境完整。
