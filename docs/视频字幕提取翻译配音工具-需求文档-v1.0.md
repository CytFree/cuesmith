## 1. 需求确认

复述用户诉求，确保对齐：

- **一键式流水线**：用户上传视频 → 选择目标语言 → 自动完成「字幕提取 → 字幕翻译 →（可选）音轨配音成目标语言」
- **替代收费软件**：自建管线，目标成本低于商用方案 1/10
- **本次目标**：代码暂缓，先固化和确认本需求文档

一句话定义产品：**上传一个视频，还你一个"目标语言字幕 + 目标语言配音"的版本。**

## 2. 项目背景与目标

### 2.1 背景（为什么自建）

| 事实 | 数据 |
|---|---|
| 商用订阅贵 | Rask AI $39/月仅含 25 分钟，超额 $3/分钟；HeyGen 10 分钟约 ¥60–200 |
| 国内云便宜但不完整 | 通义听悟 ASR 0.6 元/小时 + 翻译 0.5 元/小时 ≈ 1.1 元/小时，但无声音克隆配音 |
| 开源生态已成熟 | faster-whisper（MIT）、PaddleOCR（Apache 2.0）、CosyVoice2（Apache 2.0）、Demucs（MIT） |

### 2.2 产品目标

- **G1**：一键上传，自动判断字幕情况（内封/硬字幕/无字幕），走对应路线提取出源语言字幕
- **G2**：一键翻译成目标语言，保留原时间轴，支持单语/双语字幕导出
- **G3**（二期）：用原视频说话人的音色，将语音换成目标语言，时间轴对齐，输出新视频
- **G4**：全流程默认本地处理，隐私可控；10 分钟视频全流程成本 ≤ ¥3

### 2.3 范围

**In Scope（三期累计）**
本地视频文件 → 三路线字幕提取 → LLM 翻译 → 单语/双语字幕导出 → 声音克隆配音 → 时间伸缩适配 → 混音合成 → 唇形同步（可选开关）

**Out of Scope（本期不做）**
实时直播字幕、多人协作审校平台、移动 App、计费系统、多租户 SaaS 化

## 4. 功能需求

### FR-1 视频上传与探测

- 支持本地文件上传（mp4/mkv/mov/avi/webm/flv/ts），拖拽或选择
- ffprobe 探测并展示：视频流、音轨（数量/语言/编码）、字幕流（数量/语言/编码：srt/ass/ssa/vtt/pgs 等）
- 按探测结果自动路由到对应提取路线
- 规格：默认单文件 ≤ 2GB、时长 ≤ 3 小时（可配置）

### FR-2 字幕提取（三路线自动路由）

| 路线 | 触发条件 | 技术方案 | 预期准确率 |
|---|---|---|---|
| A 内封字幕 | 存在文本型字幕流 | ffmpeg `-map 0:s:N` 抽取；ass→srt 转换 | 100%（原文直出） |
| B 硬字幕 OCR | 无字幕流但画面有字幕 | 关键帧采样 + PaddleOCR + 字幕区域检测 + 去重去台标 + 时间轴生成 | ≥ 90% |
| C ASR | 无任何字幕 | faster-whisper large-v3-turbo（GPU）/ medium（CPU） | 清晰人声 ≥ 95% |

- B 路线要求：底部字幕条带区域检测、多行合并、相邻帧同文本去抖
- C 路线要求：语种自动识别、句级时间戳、VAD 过滤静音段

### FR-3 字幕翻译（LLM）

- 输入：源语言 SRT + 源语言 + 目标语言
- 批量送 LLM（每批 10–20 条，带上下文），硬约束：
  - 只译文本，**不动时间轴、不增删条目**
  - 控制每行长度（中文 ≤ 20 字/行，英文 ≤ 42 字符/行）
  - 术语/人名前后一致
- LLM 可配置：DeepSeek / Qwen / Claude / GPT（API Key 用户自备）；另提供本地 opus-mt 离线兜底模式
- 输出校验：条数一致、时间轴逐条不变、无漏译空译；失败自动重试 1 次

### FR-4 字幕导出

- 格式：单语 SRT（目标语言）、双语 SRT（原文 + 译文两行）、ASS（带样式）、VTT、TXT 纯文本
- 可选：字幕烧录进视频（ffmpeg subtitles 滤镜）

### FR-5 AI 配音（二期）

- **人声分离**：Demucs/UVR 从原视频分离人声与 BGM
- **参考音色**：从分离人声中自动选取清晰片段（或用户指定时间段）
- **TTS**：CosyVoice2 / F5-TTS / GPT-SoVITS 声音克隆朗读译文（XTTS v2 禁用，CPML 商用受限）
- **时间适配**：每条配音时长 vs 原时间轴槽位；超长用 `atempo` 压缩（≤ 1.3x），仍超长则顺延偏移（策略可配置）
- **混音**：目标语言人声 + 原 BGM（BGM 默认 -12dB 避让，可调）
- **合成**：ffmpeg 替换音轨，输出 mp4（H.264/AAC）

### FR-6 唇形同步（三期，可选开关，默认关闭）

- 方案：Wav2Lip / MuseTalk / LatentSync
- **明示预期**：效果弱于商业产品（HeyGen/Rask），定位为增强项
- 仅对画面人脸区域生效；无人脸视频自动跳过

### FR-7 任务管理与结果下载

- 任务队列：上传即创建任务，异步处理，实时进度（探测 → 提取 → 翻译 → 配音 → 合成）
- 断点续跑：每阶段产物落盘，失败可从中间阶段重试
- 结果页：字幕文本预览、合成视频播放、一键打包下载（字幕/音频/视频）
- 历史任务列表，默认保留 7 天（可配置）

| 类别 | 目标指标 |
|---|---|

| 稳定 | 单任务失败不影响其他任务；长视频分段处理防 OOM |
| 并发 | 单机串行队列起步，预留并行 worker 扩展位 |

## 7. 实施计划与验收标准

### 第一期：字幕提取 + 翻译（P0，目标 1–2 周）

- **交付**：上传 → 探测 → 三路线提取 → LLM 翻译 → 单语/双语字幕下载
- **验收标准**：
  - AC-1 内封 MKV 抽出的 SRT 与源字幕流逐条一致（100%）
  - AC-2 无字幕 10 分钟视频 ASR 生成 SRT，人工抽检错字率 ≤ 5%
  - AC-3 翻译后条数/时间轴与原文 100% 一致，抽检翻译可用
  - AC-4 端到端 10 分钟视频 ≤ 15 分钟（GPU 环境）
- **里程碑 M1**：替代 Veed / Subtitle Edit 的字幕功能

### 第二期：AI 配音（P1，+1–2 周）

- **交付**：人声分离 → 音色克隆 → 译文 TTS → 时间适配 → 混音 → 合成视频
- **验收标准**：
  - AC-5 克隆音色与原文说话人主观相似度 ≥ 4/5
  - AC-6 配音语音可懂度 ≥ 95%，无截断
  - AC-7 每条配音起始偏移 ≤ 0.3s
  - AC-8 BGM 完整保留，人声清晰度不低于原视频
- **里程碑 M2**：替代 Rask AI 核心配音能力（无唇形同步）

### 第三期：唇形同步 + 工程化（P2，+2–4 周）

- **交付**：Wav2Lip/MuseTalk 可选开关；批量队列；历史任务管理
- **验收标准**：
  - AC-9 有人脸视频开启后嘴型基本对齐（主观 ≥ 3/5，明示低于商业产品）
  - AC-10 连续 10 个任务无人工干预跑通
- **里程碑 M3**：功能对标完成，转入稳定性打磨

## 8. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 唇形同步效果差距 | M3 验收打折 | 设为可选开关，管理预期；跟踪 LatentSync 等新模型 |
| 声音克隆许可证 | 商用法律风险 | 仅用 Apache/MIT 协议模型；XTTS v2 禁用 |
| GPU 依赖 | CPU 模式慢 5–10 倍 | 模型分档（large/medium/small）；CPU 模式降级 medium + 关闭配音 |
| 长视频 OOM/中断 | 任务失败 | 分段处理 + 断点续跑 + 磁盘缓存 |
| LLM API 成本/限流 | 翻译失败或超支 | 批量 + 重试 + 本地 opus-mt 兜底 |
| 硬字幕 OCR 噪声（台标/弹幕/水印） | 提取文本混杂 | 区域检测 + 置信度过滤 + 校对界面（可后置） |
| ffmpeg 分发合规 | 对外产品化受限 | 自用不受影响；对外分发时替换 PyAV 或做合规审查 |
